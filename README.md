# MAISON FLORE — Day 19

A light, flowery concept website for a couture florist and glasshouse garden.

- **Blooming headings**: letters rise in, then real flowers (roses, peonies, ranunculus, cherry blossom) grow around the words, with a vine drawing underneath.
- **3D bee** (three.js) roams the page by itself, landing on headings, words and buttons.
- **3D butterfly** follows the cursor and, when the cursor rests, settles on the nearest text, nav link or button.
- **Scroll film**: a rose bud blooming, scrubbed frame by frame on scroll (full-quality frames).
- **Order flowers**: collection with occasion filters, build-your-own bouquet, bag drawer with delivery date/slot and card message.
- **Book the garden**: garden visits, golden-hour shoots, workshops and private suppers, with a blooming calendar, time slots and guests.

Open `index.html` through any static server (e.g. GitHub Pages or `python3 -m http.server`).
